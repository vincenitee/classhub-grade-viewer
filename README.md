# Classhub GradeViewer

**Classhub GradeViewer** is a simple web-based system for managing and viewing student grades, built for **LHS Senior High School**. It provides an easy-to-use platform for both students and faculty members to interact with academic data.

## 🎓 Purpose

The system is designed to:
- Allow students to **view their grades** online
- Help faculty members **manage student records**, subjects, and grades
- Provide an organized and responsive interface for grade viewing and management

## 💻 Technologies Used

- **HTML & CSS** – Page structure and styling  
- **Bootstrap 5** – Responsive layout and UI components  
- **JavaScript** – Client-side interaction  
- **PHP** – Server-side logic and data processing  
- *(Optional: MySQL or another database if you're using one)*

## 📌 Features

- Student and faculty login system
- Grade viewing for students
- Faculty dashboard for managing:
  - Student information
  - Subjects
  - Grades
- Responsive design for mobile and desktop use
